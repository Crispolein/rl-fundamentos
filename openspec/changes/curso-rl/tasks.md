# Cola de tareas del curso de RL

Fuente de verdad: `proposal.md`; detalle: `design.md`. Se toma la primera tarea `[ ]` sin `bloqueada`, con TDD
(test primero, verlo fallar, luego implementar), se corre la `verification` y se pega su salida en el commit.
Todos los comandos asumen el venv activado (`. .venv/bin/activate`), que crea T1, y CPU Linux.
Las tareas T1–T12 son infraestructura (núcleo, evaluación, entornos); cada lección L0–L12 ocupa 1 o 2 tareas.
`X` en las tareas de notebook es el nombre del archivo de esa tarea, y su verificación es el patrón de `design.md` §6:
`jupytext --to ipynb --set-kernel python3 notebooks/X.py && RLF_TRAIN_SEED=1 pytest --nbmake --nbmake-timeout=600 notebooks/X.ipynb && pytest --nbmake --overwrite --nbmake-timeout=600 notebooks/X.ipynb`
(escrito completo en cada línea).
